# gogglebox
Created a landing page for a fictional brand named Gogglebox that uses HTML, CSS, JQuery, and the TVMaze API for tomorrow's show listings using ajax.

## TVMaze API Schedule
Utilizes TV Maze's API to fill out 24 cards to display tomorrow's show listings with clickable links to their respective TV Maze Show info page.

[TV Maze API](https://www.tvmaze.com/api#schedule)

### API Call done with AJAX via JQuery
With JQuery I was able to leverage ajax to make a GET request to TV Maze and structure my call with the appropriate data field and return object.
